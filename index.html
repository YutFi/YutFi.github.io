Final-year project · 2026Power BI · Python · IoTSolo build

HiveWatch

A bee-colony health dashboard for the UiTM Dungun apiary. Temperature, humidity, rainfall and honey yield for four Kelulut hives.

  • Modelled five datasets — 22,000+ IoT sensor records plus rainfall, harvest and national beekeeping data — into a galaxy schema with four fact tables and conformed date and hive dimensions.
  • Built the ingestion and cleaning pipeline in Power Query, then used a Python regression model to impute missing honey-production values, calibrated against a published field study.
  • Flagged a known rain-gauge fault (Jan–Feb 2024, Hives 1 and 3) inside the report itself rather than quietly smoothing it over, so users know which readings to distrust.
  • Structured the four pages with the OSEMN framework and shipped a 15-section user manual written for readers with no Power BI experience.

## Tech

- Plain HTML, CSS and vanilla JavaScript in a single [`index.html`](./index.html)
- [Google Fonts](https://fonts.google.com/): Archivo, Archivo Expanded, Inter Tight, JetBrains Mono
- `<canvas>` for the hero animation (scattered points resolving into a trend line)
- `IntersectionObserver` for scroll reveals, the scroll-spy nav and count-up numbers
- Images, documents and event videos are hosted on Google Drive and embedded or linked from there

## Accessibility and responsiveness

- Skip-to-content link, visible keyboard focus, and ARIA labels on the menu, filters and lightbox
- Respects `prefers-reduced-motion` (animations are switched off or shown in their final state)
- Mobile layout with a slide-down menu; hover effects are disabled on touch screens
- If a Drive image fails to load, the page shows an "image unavailable" caption instead of a broken image

## Run locally

Open [`index.html`](./index.html) in a browser. To serve it over HTTP instead:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

This is a GitHub user site (`<username>.github.io`), so GitHub Pages publishes the `main` branch root automatically. Pushing to `main` updates https://yutfi.github.io within a minute or two.

## Editing the content

Everything lives in [`index.html`](./index.html). Each section has an `id`: `#work`, `#skills`, `#experience`, `#education`, `#contact`.

- **Colours and type sizes:** CSS variables at the top of the `<style>` block (`:root`).
- **Headline:** the `.thesis` line in the hero. Alternative headlines are in an HTML comment just above it.
- **Skills:** add a row inside `#skillgrid`:
  ```html
  <div class="grid-row" data-cat="code"><span class="idx"></span><span class="nm">Skill name</span><span class="cat">Programming</span><span class="nt">Where I use it</span></div>
  ```
  `data-cat` must be one of `viz`, `model`, `db`, `auto`, `code`, `flow`, `design`, `tool`, `soft`. Numbering and row counts are generated by the script.
- **Photos:** `<img>` tags use the Drive thumbnail format `https://drive.google.com/thumbnail?id=FILE_ID&sz=w1400`. The file must be shared as "Anyone with the link".
- **Event videos:** add `data-video="DRIVE_FILE_ID"` and `data-cap="Caption"` to a `.doc-vid` button. The lightbox opens the Drive preview player.
- **Dates and status:** the "Now" chip, the internship readout and the contact paragraph carry dates. Update them when the status changes.
